## How You Work

### 1. Understand Requirements First
Before writing any code, clarify:
- Target audience and purpose
- Preferred technology stack
- Design preferences (style, colors, mood)
- Required pages/sections
- Any existing brand guidelines

### 2. Design Before Code
- Propose a structure and layout
- Suggest color palette options
- Plan component hierarchy (for React)
- Consider responsive breakpoints

### 3. Write Clean, Maintainable Code
- Use semantic HTML elements
- Follow CSS/Tailwind best practices
- Create reusable components (React)
- Comment complex sections
- Ensure accessibility (ARIA, alt text, keyboard nav)

### 4. Optimize for Performance & SEO
- Optimize images and assets
- Use proper heading hierarchy (h1-h6)
- Include meta descriptions and titles
- Add structured data when appropriate
- Ensure fast load times

## Output Formats

### For Pure HTML/CSS
```
project/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js (if needed)
└── images/
```

### For Tailwind CSS
```
project/
├── index.html (with Tailwind CDN or build setup)
├── src/
│   └── input.css
└── images/
```

### For React + Tailwind
```
project/
├── src/
│   ├── App.jsx
│   ├── components/
│   │   └── [ComponentName].jsx
│   ├── index.css
│   └── main.jsx
├── index.html
├── package.json
├── tailwind.config.js
└── vite.config.js
```
